# Metric Dictionary

All KPIs and calculated metrics used across the Frammer Analytics dashboard.

---

## Core KPIs (Executive Summary)

| Metric | Formula | Unit | Source |
|--------|---------|------|--------|
| **Videos Uploaded** | `COUNT(video_id)` | integer | `fact_videos` |
| **Processing Rate** | `COUNT(is_processed=True) / COUNT(video_id) × 100` | percentage | `fact_videos` |
| **Publish Rate** | `COUNT(is_published=True) / COUNT(video_id) × 100` | percentage | `fact_videos` |
| **Total Duration** | `SUM(duration_seconds) / 3600` | hours | `fact_videos` |

### Sparkline Data
Each KPI card includes a 30-day sparkline. The sparkline data is generated by the `/api/executive/sparklines` endpoint, which groups by date and calculates daily values.

### Period Comparison
The KPI cards show change percentages comparing the current period to the previous equal-length period. For example, if viewing the last 7 days, the comparison is against the 7 days before that.

## Funnel Metrics (Publishing Funnel)

| Metric | Formula | Description |
|--------|---------|-------------|
| **Uploaded Count** | `COUNT(video_id)` | Total videos that entered the pipeline |
| **Processed Count** | `COUNT(is_processed=True)` | Videos that completed AI processing |
| **Published Count** | `COUNT(is_published=True)` | Videos that were published to a platform |
| **Processing Rate** | `processed / uploaded × 100` | Conversion rate: upload → process |
| **Publishing Rate** | `published / processed × 100` | Conversion rate: process → publish |
| **Overall Rate** | `published / uploaded × 100` | End-to-end conversion rate |
| **Processing Drop-off** | `uploaded - processed` | Videos that failed or stalled at processing |
| **Publishing Drop-off** | `processed - published` | Videos processed but never published |

## Trend Metrics (Usage & Trends)

| Metric | API Key | Aggregation |
|--------|---------|-------------|
| **Uploaded** | `uploaded` | `COUNT(video_id)` grouped by time bucket |
| **Processed** | `processed` | `COUNT(is_processed=True)` grouped by time bucket |
| **Published** | `published` | `COUNT(is_published=True)` grouped by time bucket |
| **Duration** | `duration` | `SUM(duration_seconds) / 3600` grouped by time bucket |

### Granularity Options
- **Daily**: Each data point = 1 calendar day
- **Weekly**: Each data point = 1 ISO week (Mon–Sun)
- **Monthly**: Each data point = 1 calendar month

### Period Comparison
The comparison overlay shows the same metric for the previous equal-length time range. The `change_pct` value indicates the percentage change between periods.

## Analysis Metrics

| Metric | API Key | Used In |
|--------|---------|---------|
| **Uploaded** | `uploaded` | Leaderboard ranking, pivot table cells |
| **Processed** | `processed` | Leaderboard ranking, pivot table cells |
| **Published** | `published` | Leaderboard ranking, pivot table cells |
| **Duration (hours)** | `duration` | Leaderboard ranking, pivot table cells |

### Leaderboard
Top-N entities ranked by the selected metric. Shows rank, value, and a proportional progress bar (relative to the #1 entity's value).

### Pivot Table
Cross-tabulation of two dimensions (e.g., Client × Channel), with each cell showing the selected metric's value. Row and column totals are calculated client-side.

### Drilldown
Clicking a leaderboard entry loads a drilldown panel with:
- Total uploaded, processed, published counts
- Total duration in hours
- Radar chart overlay of all 4 metrics (normalized)

## Anomaly Detection

| Metric | Formula | Threshold |
|--------|---------|-----------|
| **Z-Score** | `(value - mean) / stddev` | Alert if `|z| > 2.0` |

Applied to daily upload counts over the trailing 30-day window. Days with z-scores above 2.0 or below -2.0 are flagged as anomalies and displayed as alert cards on the Executive Summary.

## Data Quality Metrics

| Metric | Formula | Description |
|--------|---------|-------------|
| **Quality Score** | Weighted composite (0-100) | `0.4 × missing_score + 0.3 × unknown_score + 0.2 × orphan_score + 0.1 × dup_score` |
| **Missing Score** | `100 - avg_missing_pct × 2` | Penalizes NULL/empty fields |
| **Unknown Score** | `100 - unknown_pct × 5` | Penalizes placeholder dimension values |
| **Orphan Score** | `100` if 0 orphans, else heavily penalized | Penalizes broken foreign keys |
| **Duplicate Score** | `100 - dup_count × 5` | Penalizes duplicate titles |
| **Field Completeness** | `(total - missing) / total × 100` per field | Per-field completion percentage |
